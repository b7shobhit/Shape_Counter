# 📐 Shape Intelligence Suite
A collection of interactive web tools built with Vanilla JS to solve complex geometric counting puzzles.

## 🚀 Live Demo
https://b7shobhit.github.io/Shape_Counter/#-the-collection

## 🧩 The Collection
This suite includes three distinct tools designed to automate geometric calculations:

1. **Star Triangle Counter**: Calculates the total number of nested and overlapping triangles within a star polygon.
2. **Chessboard Square Logic**: A tool to visualise and calculate the total number of squares (from 1x1 to 8x8) on a standard grid.
3. **Chessboard Grid Analyser**: A flexible tool that calculates the total number of both squares and rectangles for chessboard grid.

## 🛠️ Technical Highlights
- **Zero Dependencies**: Built entirely with pure HTML.
- **Algorithmically Driven**: Uses mathematical logic to handle complex grid combinations rather than hard-coded values.
- **Instant Execution**: Runs entirely client-side for maximum speed and privacy.

## 📖 How to Use
1. Open the Live demo.
2. Select the specific counting tool from the dashboard.
3. Interact with the UI to see real-time calculation results.
