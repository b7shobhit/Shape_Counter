# 📐 Shape_Counter
A collection of interactive web tools built with HTML to solve geometric logic puzzles.

## 🧩 The Collection
1. **Star Triangle Counter**: Calculates triangles within a star polygon.
2. **Chessboard Square Logic**: Calculates all possible squares on an 8x8 grid.
3. **Chessbaord Grid Analyser**: Calculates both squares and rectangles for 8x8 grid.

## 🛠️ Tech Stack
- HTML5.
